# Drops manuels

Pose ici tes `.glb` (ou `.gltf`) faits à la main, commit, push.

Exemple :
```
cp ~/Desktop/mon-modele.glb assets/aurora/manual/
git add assets/aurora/manual/mon-modele.glb
git commit -m "aurora: ajout manuel mon-modele"
git push
```

Une fois Vercel redéployé, le fichier est servi à `/assets/aurora/manual/mon-modele.glb`.
